# RodiArt

Одностраничный сайт на русском, украинском, греческом и английском. Чёрно-красное оформление,
логотип из предоставленного RodiArt_3.pdf, разделы «О нас», «Наши работы» и связь
через Instagram. Сайт работает без Python, Node.js и установки зависимостей.

## Открыть

Откройте `dist/index.html` двойным щелчком. Язык выбирается по списку предпочтений браузера: русский, украинский, греческий или английский. Если подходящего языка нет, открывается английская версия.
Переключатель RU / UA / EL / EN меняет все тексты, включая подписи в шапке.
Параметры `?lang=ru`, `?lang=uk`, `?lang=el`, `?lang=en` позволяют задать язык ссылкой с приоритетом над настройками браузера.

Для публикации на статическом хостинге загрузите содержимое папки `dist`.
Внешние шрифты загружаются из Google Fonts; без сети используются системные шрифты.
Кнопки связи и ссылка на дополнительные работы открывают Instagram в новой вкладке. В разделе контактов указан адрес ателье и ссылка на Google Maps.
Фотографии открываются в полном размере по нажатию. Эскиз не кликабелен. Вся запись его рисования ускорена до 10 секунд, после чего итоговый кадр удерживается ещё 1 секунду. Видео запускается при прокрутке без звука и кнопок; при отключённых анимациях остаётся обложка из финального кадра.

## Материалы

- Тексты основаны на описании заказчика; Instagram не удалось прочитать автоматически.
- Логотип отображается из первой страницы PDF, преобразованной штатным PDF-рендерером Windows.
- Оригинальный PDF сохранён в `dist/assets/RodiArt-logo.pdf`.
- В разделе работ размещены две реальные фотографии платьев, предоставленные заказчиком:
  `platie1.JPG` и `platie2.JPG`. Копии оригиналов сохранены в `dist/assets`.
- Эскиз `eskiz.jpg` иллюстрирует отдельный блок о совместной работе клиента и дизайнера:
  пожелания, форма, ткани и декор, визуализация, изготовление в ателье.
- Небольшой логотип перенесён в шапку, без рамки. Красный усилен CSS-фильтром;
  исходное изображение не изменено.

Для дальнейших правок: `dist/index.html` — структура, `dist/styles.css` — оформление,
`dist/script.js` — переводы и переключение языков.

Видео работы в ателье размещено после эскиза: dist/assets/dress-making.mp4. Ролик обрезан до 12,5 секунды, конвертированная в H.264 MP4 без звука. Запускается при прокрутке без кнопок управления.
