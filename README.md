# RodiArt

Одностраничный сайт на русском, украинском, греческом и английском. Чёрно-красное оформление,
логотип из предоставленного RodiArt_3.pdf, разделы «О нас», «Наши работы» и связь
через Instagram. Сайт работает без Python, Node.js и установки зависимостей.

## Открыть

Откройте `dist/index.html` двойным щелчком. Основная страница — на русском;
`dist/el/index.html`, `dist/uk/index.html`, `dist/en/index.html` — полностью переведённые страницы,
доступные без JavaScript. Переключатель RU / UA / EL / EN открывает отдельную страницу.
Старые ссылки с `?lang=ru`, `?lang=uk`, `?lang=el`, `?lang=en` перенаправляют на соответствующую страницу.

Для публикации на статическом хостинге загрузите содержимое папки `dist`.
Внешние шрифты загружаются из Google Fonts; без сети используются системные шрифты.
Кнопки связи и ссылка на дополнительные работы открывают Instagram в новой вкладке. В разделе контактов указан адрес ателье и ссылка на Google Maps.
Фотографии открываются в полном размере по нажатию. Эскиз не кликабелен. Вся запись его рисования ускорена до 10 секунд, после чего итоговый кадр удерживается ещё 1 секунду. Видео запускается при прокрутке без звука и кнопок; при отключённых анимациях остаётся обложка из финального кадра.

## Материалы

- Тексты основаны на описании заказчика; Instagram не удалось прочитать автоматически.
- Логотип отображается из первой страницы PDF, преобразованной штатным PDF-рендерером Windows.
- Оригинальный PDF сохранён в `dist/assets/RodiArt-logo.pdf`.
- В разделе работ размещены две реальные фотографии платьев, предоставленные заказчиком:
  `platie1.JPG` и `platie2.JPG`. Копии оригиналов сохранены в `dist/assets`.
- Эскиз `eskiz.jpg` иллюстрирует отдельный блок о совместной работе клиента и дизайнера:
  пожелания, форма, ткани и декор, визуализация, изготовление в ателье.
- Небольшой логотип перенесён в шапку, без рамки. Красный усилен CSS-фильтром;
  исходное изображение не изменено.

Для дальнейших правок: `site/index.html` — шаблон структуры, `dist/styles.css` — оформление,
`dist/script.js` — переводы и переключение языков.

## Аналитика посещений

Google Analytics и всплывающий блок удалены. `dist/analytics.js` удаляет старые
cookies `_ga*` и прежний выбор согласия. Umami Cloud подключён:
Website ID: `526d0018-589c-4673-867a-f609e24f2c71`, script: `https://cloud.umami.is/script.js`.
Укажите `websiteId` и `trackerUrl` из этого кода в начале `dist/analytics.js`.
Информация об аналитике размещена в `dist/privacy.html` на четырёх языках с учётом
фактического сервиса, хранения данных и применимых требований.

Подготовлены события `instagram_click` и `map_click`, параметры
`page_language`, `link_placement`. Сбор разрешён только на HTTPS-доменах
`rodiart.gr` и `www.rodiart.gr`; локальное превью не учитывается.
Новые cookies кодом интеграции не устанавливаются. Параметры запроса и фрагмент
URL исключены, Do Not Track учитывается. После включения проверяйте данные в Umami.

## Поисковые метаданные

Приоритетные поисковые языки — греческий и русский. Поисковые тексты ориентированы
на Афины; физический адрес ателье сохраняет Аргируполи. У каждой языковой страницы есть
canonical, взаимные hreflang, метаданные Open Graph и JSON-LD LocalBusiness/WebPage.
Адрес и Instagram взяты из существующего сайта; цены, часы работы и отзывы не добавлялись.
`dist/sitemap.xml` перечисляет страницы, `dist/robots.txt` разрешает обход.
На GitHub Pages файл robots.txt проекта находится в подпапке; правила для всего домена
можно задать только в его корне. Sitemap можно отдельно отправить в Google Search Console
и Bing Webmaster Tools после публикации.

После изменения шаблона или переводов выполните из корня проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-seo.ps1
```

По умолчанию используется постоянный URL `https://rodiart.gr/`.
Для другого адреса передайте `-SiteUrl https://example.com/`.
GitHub Actions использует `SITE_URL: https://rodiart.gr/` в `.github/workflows/pages.yml`.
При смене домена обновите также это значение. Генерируемые HTML в `dist` не редактируйте вручную.
Локальная генерация не требует Node.js или установки зависимостей. Индексация и позиции
зависят от поисковых систем; наличие разметки само по себе их не гарантирует.

Видео работы в ателье размещено после эскиза: dist/assets/dress-making.mp4. Ролик обрезан до 12,5 секунды, конвертированная в H.264 MP4 без звука. Запускается при прокрутке без кнопок управления.
